   ✅ Check: Server IP in App.js matches actual IP
   ✅ Check: Server is running (npm start in server/)
   ✅ Check: Both phones on same WiFi

❌ "No other users available"
   ✅ Check: Other phone has CommentScreen open
   ✅ Check: 3 sec passed for list update
   ✅ Try:   Close modal and reopen

❌ Video doesn't display
   ✅ Check: Granted camera/mic permissions
   ✅ Check: Phone has working camera
   ✅ Try:   Restart app

❌ Server won't start
   ✅ Check: Node.js installed (node --version)
   ✅ Check: Dependencies installed (npm install in server/)
   ✅ Check: Port 3000 free (netstat -ab | grep 3000)

❌ Frequent disconnects
   ✅ Check: WiFi signal strength
   ✅ Try:   Move closer to router
   ✅ Try:   Restart app and server
